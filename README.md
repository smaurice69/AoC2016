# Advent of Code 2016 + Chess Engine Setup

This repository originally contained solutions for Advent of Code 2016. It now also includes a minimal C++ project for a UCI-compatible chess engine.

## Chess Engine Project

See `ChessEngine/README.md` for instructions on building the chess engine using VS Code on macOS and Visual Studio 2022 on Windows.
The engine now understands simple UCI commands and can parse a FEN position.
